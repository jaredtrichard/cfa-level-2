# Practice storage

Create `practice/<topic>/<case>-prompt.md` and `<case>-solution.md` only for the selected lesson. Prompts contain original open-response cases and outcome IDs. Solutions contain checked reasoning, assumptions, calculations, source edition/section, and a rubric for explain/calculate/apply. Keep the solution out of the learner-facing prompt.

Create separate validation cases when needed. Record whether a prompt is unseen, attempted, hinted, or solution-exposed in the private attempt log; a shown case is no longer unseen. Preserve the exact prompt and rubric used in each assessment so later file edits cannot rewrite history.
